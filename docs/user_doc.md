# User Document

## Goal

When setting a password, you usually run into a tricky problem:

- If the password is too simple, it's easy to crack.
- If different account with the same password, it's easy to crack, too.
- If the password is too complicated, it's easy to forget.

The goal of the APP is:

- Generate strong password by simple string.
- Generate different passwords by the same string.

## Usage

### Add account infomation

Usually do this while create a real account.

1. Choose a simple password as Main Password.
1. Click the Add button in the bottom right corner.
1. Fill in the form. User Name is account name, Platform is the platform of the account, for example, gmail. And you can also set up other options.
1. Enter your Main Password, press `Enter` , the generated password will show up in below and you can use it as the password for your real account.
1. If the generate is suitable, click Save button in the top right corner.

### Other Feature

- You can search account infomation by username and platform.
- The item of table in main page is clickable, you can edit/delete account infomation inside it.
- You can backup and restore data in settings page.

## Caveat

- The generated password is related to the **User Name**, **Platform**, **Nonce Offset** and **Main Password**.
- Remember your **Main Password**. **Main Password** will not be saved.
